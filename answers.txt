When I type a website address like google.com and press Enter, sends a request to the internet. DNS finds Google's IP address, then the browser connects to Google's server and downloads the webpage.
A client is a device or application that requests services
Domain Name System(DNS) translates website names, such as google.com, into IP addresses that computers use to find each other on the internet.DNS makes it much easier for people to remember website names than long strings of numbers.
A firewall acts like a security guard that decides what traffic is allowed through.A load balancer distributes incoming requests across multiple servers so that no single server becomes overloaded. A firewall focuses on security by filtering and blocking unwanted traffic, while a load balancer focuses on performance and reliability by sharing traffic among multiple servers.
A web server receives requests from users' browsers and serves static content such as HTML, CSS, images, and files.An application server runs the application's business logic, processes user requests, interacts with databases, and generates dynamic content before sending the response back to the web server.A backend developer works more with the application server because it is where the application's logic is written.
The client never communicates directly with the database because it would expose sensitive data and create security risks.An application server validates user input to prevent errors and attacks and handles the application's business logic and rules.
A university department page (such as ug.edu.gh/statistics) is more likely to be a static website because it mainly displays information such as department details, programs, staff, and announcements that do not change frequently or depend on the individual visitor.An MTN MoMo account page is a dynamic website because it shows personalized information such as your account balance, transaction history, and account details.
The frontend is the part of a website that users see and interact with, such as buttons, forms, and web pages. The backend is the part that runs on the server, processes requests, manages the database, and handles the application's logic.If I were building a login feature, the backend would handle checking the password against the database. This is because passwords and user data must be kept secure. The backend verifies the login details and only returns a success or failure response to the frontend, preventing users from accessing the database directly.
